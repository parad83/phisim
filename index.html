• works best on computer screens;
  • following operators can be used: +, -, *, /, ^, (, ), standard functions such as: exp, ln, sin, cos, tan, abs, sqrt; and pi;
  • use [A-Za-z]+ for variables;
  • you can change the tick count for the whole graph as well as step sizes for the axis;
  • on default all the equations are rendered with 400 vertices but you can change that with the sample size;
  • you can change the function type in the dropdown;
  • I could not be bothered to write a parser for decimals, so use fractions;
  • raw equations are parsed with Pratt parsing and evalated on the GPU;
  • unfortunately you can't delete equations once you graph them so be careful!
